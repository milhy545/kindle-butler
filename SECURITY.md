# Security Policy

## Supported Versions

Currently, only the latest release of Kindle Butler is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please DO NOT report it by creating a public GitHub issue.

Instead, please send an email to the repository owner or use the private vulnerability reporting tool in GitHub (if enabled for this repository). 

Please include the following in your report:
- A description of the vulnerability.
- Steps to reproduce.
- Any possible mitigation or patch you might have.

We will do our best to confirm the issue and issue a patch as quickly as possible. We prioritize responsible disclosure and take the security of your Kindle files seriously.
